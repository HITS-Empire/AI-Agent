Лаба 1 (1 месяц, 60 баллов)

За первый месяц вам нужно написать ядро и harness для своего персонального ИИ-ассистента. Вы можете вдохновляться open-source решениями, но не можете их использовать. Наработки первого модуля лягут в основу вашего проекта. Во втором модуле вам потребуется доработать кодовую базу ассистента по новым требованиям.

## Ядро агента (30 баллов)

Ядро агента — самодельный базовый цикл агента с нативным tool calling (без библиотек).

Обязательно должно быть реализовано (каждый критерий — по 5 баллов):

- работа с файловой системой (чтение и редактирование файлов), в том числе реализовать:
  - стандарт AGENTS.md
  - стандарт SKILL.md
  - иерархическое чтение структуры каталога
- подключение к LLM-шлюзу
- подключение к MCP-серверам
- вызов shell-команд и другие нативные инструменты для работы с ОС
  - Windows Powershell (v7 и выше)
  - Linux terminal
  - MacOS (если есть)
- пользовательский интерфейс взаимодействия
- работа с context window и compaction контекста

## Обязательные компоненты архитектуры / harness (20 баллов)

Каждый компонент архитектуры оценивается в 4 балла:

1. LLM-шлюз — единая точка всех вызовов моделей на базе LiteLLM Proxy или аналога: учёт токенов, бюджеты, маршрутизация, логирование. Прямые вызовы API в обход шлюза запрещены.
2. Память — краткосрочный контекст диалога и долговременная память (с применением векторного поиска, но не ограничиваясь им).
3. Интерфейсы — не менее двух каналов связи с владельцем (интерфейсов).
   1. Один из них — асинхронный мессенджер: Telegram-бот, CLI/TUI, веб-интерфейс, e-mail, голос (локальный Whisper + TTS), Matrix. Интерфейс обязательно должен содержать на видном месте название проекта «бурмалда».
   2. Все интерфейсы разделяют общую память и очередь задач: начатое в Telegram можно продолжить в CLI.
4. Песочница — весь исполняемый агентом код и shell-команды работают в изолированном контейнере (если не реализуете - крайне рекомендуется запускать агента на ВМ, чтобы не создать риск деструктивных изменений в свое устройстве).
5. Наблюдаемость — структурированные логи, трассировка вызовов (OpenTelemetry, Langfuse или Phoenix), дашборд расхода.

## Функциональность ассистента (10 баллов)

Базовые скиллы / тулы (по 1 баллу каждый):

1. Поиск информации в интернете
2. Напоминания (человеку) по заданному расписанию
3. Интеграция с личным календарем
4. Интеграция на чтение с внешним календарем (расписание в вашем ВУЗ-е, или расписание турниров в вашем любимом виде спорта, или тому подобное)
5. Интеграция с GitHub

Дополнительно можно реализовать (до 5 баллов):

- навык полноценного поиска товарам по нескольким маркетплейсам
- подключение к вашему умному дому (если есть) и выполнение базовых команд

Напомню, что каждому члену вашей команды потребуется прикрепить артефакт решения задачи, а также записаться на защиту!
