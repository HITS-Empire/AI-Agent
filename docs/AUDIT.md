## Главные риски

1. **Песочница** — код контейнера на сессию есть, но в этой среде нет Docker: живой `rm -rf /` внутри контейнера не показан. Аргументы `docker run` и allowlist покрыты юнит-тестами.
2. **ФС + AGENTS.md + SKILL.md** — закрыто тестами без модели (26.11). На живой модели ещё не прогонялось: это проверяет A.
3. **Общая очередь для Telegram и CLI (B)** — код обоих каналов на одной сессии есть (`ownerSession`, `enqueueAgentTask`, кнопки подтверждения). Живой прогон через Redis и Telegram API в этой среде не делался: нет Redis и токена.
4. **PowerShell 7** — код отказывается от версии ниже 7, но живого `pwsh` в этой среде нет. Нужна проверка на Windows (CI или машина B).
5. **Маркетплейсы без обхода защиты** — 24.11 все три площадки ответили headless Chromium защитой (Маркет 403 по IP, Ozon 403-антибот, WB 498-антибот); повтор 25.11 (WB с ожиданием 90 с, Ozon одна попытка) — то же. Инструмент честно пишет, что площадки недоступны. Обходы (stealth, прокси, решатели капч) и платный агрегатор Market Ninja не используем — решение команды.
6. **GitHub** — нужен fine-grained токен только на чтение для живой демонстрации.
