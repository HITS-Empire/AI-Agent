## Главные риски

1. **Песочница и shell (B)** — 5 баллов ядра + 4 harness зависят от одного куска; без него нельзя честно показать «код агента изолирован».
2. **ФС + AGENTS.md + SKILL.md (B)** — 5 баллов; без `load_skill` навыки A работают только косвенно (проверено временной заглушкой).
3. **Общая очередь для Telegram и CLI (B)** — критерий формулирует это явно; worker и шина уже готовы.
4. **PowerShell 7** — нужна живая проверка на Windows.
5. **Маркетплейсы без обхода защиты** — живой поиск может упираться в капчу на всех площадках.
6. **GitHub** — нужен fine-grained токен только на чтение для живой демонстрации.
