# Поиск товаров по маркетплейсам

1. Уточни, только если без этого поиск бессмыслен: что за товар и бюджет. Остальное (бренд, характеристики) — из запроса или по умолчанию.
2. Составь короткий поисковый запрос на русском: тип товара + ключевые признаки («беспроводные наушники с шумоподавлением»), без слов «купить», «недорого».
   Если товар неоднозначный — 2–3 варианта запроса отдельными вызовами.
3. Вызови `marketplace_search` один раз на все доступные площадки; бюджет передай в `price_max` (и `price_min`, если сказано «не дешевле»).
   Для «самый дешёвый» — `sort: "price_asc"`, для «лучший» — по умолчанию (релевантность) и смотри на рейтинг.
4. Отбрось карточки, которые не подходят по сути (аксессуары вместо товара, другая модель, чехлы, запчасти).
   Дубли одной модели у разных продавцов оставь только с лучшей ценой.
5. Ответ: до 5 вариантов таблицей — площадка, название (сокращённо), цена (и старая цена, если есть), рейтинг и число отзывов, ссылка (дословно из `url`, не сокращай).
   Ниже одной-двумя строками — какой вариант лучше и почему (цена, рейтинг при достаточном числе отзывов, соответствие запросу).
6. Площадки из `unavailable` (капча, блокировка, адаптер не готов) назови и покажи результаты остальных. Не пытайся обойти защиту.
7. Укажи время, когда сняты цены (`fetchedAt`, в часовом поясе владельца): цены меняются быстро. Покупать ничего не нужно и нельзя.
